# Блокнот для Windows

Приложение для Windows к вашему Блокноту на сервере:

- устанавливается обычным установщиком `.exe`, ярлыки в меню «Пуск» и на рабочем столе;
- Блокнот открывается в отдельном окне, без вкладок и адресной строки браузера;
- значок в трее: крестик прячет окно туда, а приложение продолжает работать;
- уведомление Windows, когда на сервере появилась новая версия Блокнота (проверка раз в 30 минут и по пункту «Проверить обновления» в меню значка);
- по желанию запуск вместе с Windows (меню значка → «Запускать вместе с Windows»);
- ссылки на другие сайты открываются в обычном браузере.

Данные по-прежнему хранятся на вашем сервере, поэтому всё синхронизируется с телефоном и браузером. Без интернета приложение не работает.

## Как получить установщик (один раз, около 15 минут)

Установщик собирается бесплатно на GitHub, на их компьютере с Windows.

1. Зарегистрируйтесь или войдите на [github.com](https://github.com).
2. Создайте репозиторий: «+» вверху справа → **New repository**. Имя — например, `bloknot-windows`, тип — **Private**. Нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**. Перетащите в окно **всё содержимое** этой папки (`windows-app`): папки `.github`, `src-tauri`, `ui` и файлы `package.json`, `README.md`, `.gitignore`. Нажмите **Commit changes**.
   - Папка `.github` в Проводнике может быть скрыта (имя начинается с точки). Включите «Вид → Показать → Скрытые элементы» или просто выделите всё сочетанием Ctrl+A.
4. Откройте вкладку **Actions**. Если GitHub спросит, разрешить ли сборки, нажмите зелёную кнопку разрешения. Сборка «Блокнот для Windows» запустится сама после загрузки файлов; если нет — выберите её слева и нажмите **Run workflow**.
5. Через 10–15 минут сборка станет зелёной. Установщик лежит:
   - в разделе **Releases** справа на главной странице репозитория — файл `Блокнот_1.0.0_x64-setup.exe`;
   - или внутри запуска сборки, внизу, в блоке **Artifacts**.

Если сборка стала красной, откройте её, нажмите на красный шаг и пришлите текст ошибки — поправлю.

## Установка

1. Запустите `…x64-setup.exe`.
2. Установщик не подписан цифровой подписью (она платная), поэтому Windows покажет «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**. Это нужно один раз.
3. При первом запуске укажите адрес вашего Блокнота — тот же, что вы открываете в браузере (например, `https://notes.example.ru/`). Дальше войдите как обычно.

Если на компьютере нет компонента Microsoft Edge WebView2 (на Windows 10 и 11 он почти всегда есть), установщик скачает его сам.

## Обновления

- **Новая версия Блокнота на сервере** (вы залили обновление по FTP): придёт уведомление Windows «Блокнот обновлён до версии …», а в окне — кнопка «Обновить». Переустанавливать приложение не нужно.
- **Новая версия самого приложения для Windows** (меняется редко): загрузите новые файлы этой папки в тот же репозиторий поверх старых. GitHub соберёт новый установщик; запустите его поверх установленного приложения.
