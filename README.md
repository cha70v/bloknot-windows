# Bloknot — Блокнот для Windows

Приложение для Windows к вашему Блокноту на сервере. Называется **Bloknot** (латиницей), чтобы не путаться со стандартным «Блокнотом» Windows: так называются и папка установки `C:\Program Files\Bloknot`, и файл `Bloknot.exe`, и ярлыки.

- устанавливается обычным установщиком `.exe`, ярлыки в меню «Пуск» и на рабочем столе;
- Блокнот открывается в отдельном окне, без вкладок и адресной строки браузера;
- значок в трее: крестик прячет окно туда, а приложение продолжает работать;
- уведомление Windows, когда на сервере появилась новая версия Блокнота (проверка раз в 30 минут и по пункту «Проверить обновления» в меню значка);
- по желанию запуск вместе с Windows (меню значка → «Запускать вместе с Windows»);
- ссылки на другие сайты открываются в обычном браузере.

Данные по-прежнему хранятся на вашем сервере, поэтому всё синхронизируется с телефоном и браузером. Без интернета приложение не работает.

## Как получить установщик

Установщик собирается бесплатно на GitHub, на их компьютере с Windows.

1. Зарегистрируйтесь или войдите на [github.com](https://github.com).
2. Создайте репозиторий: «+» вверху справа → **New repository**. Имя — например, `bloknot-windows`, тип — **Private**. Нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**. Перетащите в окно **всё содержимое** этой папки (`windows-app`): папки `.github`, `src-tauri`, `ui` и файлы `package.json`, `README.md`, `.gitignore`. Нажмите **Commit changes**.
   - Папку `.github` GitHub при перетаскивании часто пропускает. Если во вкладке **Actions** нет сборки «Bloknot для Windows», создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/windows.yml`, содержимое — из одноимённого файла этой папки.
4. Откройте вкладку **Actions** (в ряду вкладок вверху; в узком окне — под «…»). Сборка запускается сама после загрузки файлов; если нет — выберите её слева и нажмите **Run workflow**.
5. Через 10–15 минут сборка станет зелёной. Установщик `Bloknot_<версия>_x64-setup.exe` лежит в разделе **Releases** справа на главной странице репозитория, а также внутри запуска сборки, в блоке **Artifacts**.

Если сборка стала красной, откройте её, нажмите на красный шаг и пришлите текст ошибки.

**Обновить приложение** (когда меняются файлы этой папки): загрузите новые файлы в тот же репозиторий поверх старых, GitHub соберёт новый установщик. Запустите его — он обновит установленное приложение. Адрес сервера и вход сохраняются.

## Установка

1. Если стоит старая версия с русским названием «Блокнот» (1.0.0), удалите её: **Параметры → Приложения → Установленные приложения → Блокнот → Удалить**. Адрес сервера и вход сохранятся.
2. Запустите `Bloknot_…_x64-setup.exe`. Windows спросит разрешение на установку в Program Files — согласитесь.
3. При первом запуске укажите адрес вашего Блокнота — тот же, что вы открываете в браузере (например, `https://notes.example.ru/`).

## Антивирус и SmartScreen

Установщик не подписан цифровой подписью: сертификат для подписи платный (от ~$100–300 в год) и выдаётся компаниям или на имя с проверкой документов. Антивирусы относятся к новым неподписанным программам настороженно — особенно в первые дни, пока у файла нет «репутации». Это ложная тревога: исходный код приложения целиком лежит в этой папке, установщик собирает GitHub.

Что можно сделать:

- **SmartScreen** («Windows защитила ваш компьютер»): **Подробнее → Выполнить в любом случае**. Один раз.
- **Антивирус** (Kaspersky, Dr.Web, ESET, Defender…): добавьте папку `C:\Program Files\Bloknot` в исключения и отправьте установщик производителю как ложное срабатывание — обычно его снимают за 1–3 дня, после чего тревога исчезает у всех:
  - Kaspersky — [opentip.kaspersky.com](https://opentip.kaspersky.com) (кнопка отправки на проверку) или [support.kaspersky.ru](https://support.kaspersky.ru);
  - Microsoft Defender — [microsoft.com/wdsi/filesubmission](https://www.microsoft.com/wdsi/filesubmission);
  - Dr.Web — [vms.drweb.ru/sendvirus](https://vms.drweb.ru/sendvirus/);
  - ESET — [support.eset.com](https://support.eset.com) (раздел про ложные срабатывания).
- Проверить файл сразу несколькими антивирусами можно на [virustotal.com](https://www.virustotal.com).
